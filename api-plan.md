# API Plan (План API)

Документ описывает планируемые эндпоинты для взаимодействия фронтенда с бэкендом мини-магазина.

## Товары (Products)
* `GET /api/products` — получить список всех товаров.
* `GET /api/products/{id}` — получить информацию о конкретном товаре.
* `GET /api/products?category=electronics` — фильтрация товаров по категории.

## Корзина (Cart)
* `GET /api/cart` — получить текущее содержимое корзины.
* `POST /api/cart` — добавить товар в корзину.
* `DELETE /api/cart/{id}` — удалить товар из корзины.
* `PATCH /api/cart/{id}` — изменить количество товара в корзине.

## Заказы (Orders)
* `POST /api/orders` — создать новый заказ.
* `GET /api/orders` — получить список заказов пользователя.
* `GET /api/orders/{id}` — получить детали конкретного заказа.

## Пользователи (Users)
* `POST /api/auth/register` — регистрация нового пользователя.
* `POST /api/auth/login` — авторизация пользователя.
* `GET /api/users/me` — получить профиль текущего пользователя.
