# Mini-Shop (Мини-магазин)

Здравствуйте!
Учебный проект небольшого интернет-магазина, созданный в рамках контрольной точки по Git.

## Описание проекта

Проект представляет собой упрощенную модель интернет-магазина.
Основная цель — демонстрация навыков работы с системой контроля версий Git:

- создание и переключение веток;
- осмысленные коммиты;
- слияние (merge) веток;
- разрешение конфликтов.

## Планируемый функционал

- Просмотр каталога товаров.
- Фильтрация и поиск товаров.
- Добавление товаров в корзину.
- Оформление заказа и оплата.

## Структура репозитория

- `README.md` — описание проекта (текущий файл).
- `project-notes.md` — заметки по ходу разработки.
- `api-plan.md` — план API для взаимодействия с бэкендом.
- `git-conflict.md` — описание возникшего и разрешенного конфликта.
- `git-network.png` — скриншот графа веток GitHub Network.

## Направление магазина

Это проект мини-магазина, который продает электронику.
